# BMI-Calculator


A simple BMI Calculator built using HTML, CSS, and JavaScript.

## Features
- Calculate Body Mass Index (BMI)
- Shows weight category:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Simple and clean UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project
2. Open `index.html` in your browser

## BMI Formula

BMI = weight (kg) / height² (m²)
